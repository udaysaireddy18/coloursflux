Install & go offline

Campus networks slow down when thousands of people arrive. Install the app and save the festival data before you reach the grounds.

A QR code only opens this website. It does not make the site available offline — you still need one successful visit with a connection.

1. Install the app

Checking…

Installing keeps ColoursFlux on your home screen and lets it open without a browser tab. It is optional — the website also works in a browser.

Android (Chrome, Edge, Samsung Internet)

Open the browser menu and choose Install app or Add to Home screen. If you see an install banner in the app, you can use that instead.

iPhone & iPad (Safari)

Tap the Share icon, then Add to Home Screen. iOS installs web apps from Safari; other browsers may not show the option.

Laptop / desktop

Look for the install icon in the address bar, or open the browser menu and choose Install ColoursFlux.

A2HS availability depends on your browser.

Print size

Print at least 4 × 4 cm with a quiet white border. Bigger is better on posters and standees.

Test on real phones

Scan from a printed copy with at least two phones, at the distance people will actually stand.

Put it near signal

Place the code where visitors still have connectivity, so the first load and data download can succeed.

Honest offline limits

  • A first-time visitor cannot open the site offline. The application shell must be cached during an earlier online visit.
  • Saved data can be outdated. The app shows the last sync time and labels offline content.
  • Live announcements require connectivity; a device that is offline cannot receive new notices.
  • Admin pages are never cached. The dashboard requires a connection and a signed-in organiser session.
